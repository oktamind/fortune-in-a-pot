A program that writes one original fortune for a houseplant on the windowsill: soon it will unfurl one perfect new leaf in the sun, while the cat pretends it never planned to eat it. A prediction with fortune cadence, a small situational joke, and a kind ending.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
